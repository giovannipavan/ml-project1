# ml-project1

## Exploratory data analysis

`stats.py` contains reusable functions that compute descriptive statistics of the
training data (fraction of missing values per feature, number of distinct values,
class balance, correlation of each feature with the labels). It uses NumPy only.

`notebooks/eda.ipynb` imports these functions and shows plots and observations
about the dataset. It requires the data files in `data/` (see the Data section).
